# 使用手册

本手册解释日常操作；环境准备见 [README](../README.md#快速开始)，输出字段见 [数据格式规范](data-format.md)。

## 打开目录与选择读者

「打开 DICOM 目录」选择存放胸片的文件夹，子文件夹也会扫描。模块只读取扩展名 `.dcm`、单帧、单通道的 CR/DX 灰度 DICOM；其他文件和重复图像会跳过。没有扩展名的 DICOM 不会进入病例列表。扫描跳过数量可在进度文字的提示中查看。

首次使用先打开目录，再从进度行的「读者」选择 01–10。显示编号 01 对应数据中的 `reader-01`，其他编号依此类推。每位读者固定使用自己的编号；更换编号后，评分、录音、空间标注和分区修订分别恢复。

病例下拉框用于跳转，左右箭头用于前后切换。「下一例」保存草稿，不要求先填完；「完成并下一例」按完成条件检查后再跳转。进度按当前读者计算，未保存的空记录也会出现在导出中。

启动器恢复上次打开的项目；没有恢复信息时，会尝试仓库相邻的 `2023Sample`。样本目录不随仓库分发；没有样本时，直接打开自己的目录即可。启动器使用独立设置，不修改日常 Slicer 配置。

## 整片质量与六肺区评分

整片质量直接选择：1 优片、2 良片、3 差片、4 废片，也可点回「未评」。质量与密集度分开记录，质量等级不是病变分期。各等级都可以满足质量评价这一项，不要求填写缺陷原因。

六肺区分别是患者右上、右中、右下、左上、左中、左下。六条滑杆共用一个带文字的标尺，12 档依次为：

```text
0/-  0/0  0/1  1/0  1/1  1/2  2/1  2/2  2/3  3/2  3/3  3/+
```

拖动并松开即保存；滑杆聚焦后，也可用左右方向键逐档调整。右侧数值是实际评分。默认状态是「未评」，滑杆初始位置不代表已评分。鼠标滚轮不会更改评分，避免滚动面板时误改。

「未评」清空该区评分并使其未完成；「不可评」记录一次有效的不可评价结论，可以完成病例。两者都不等于 `0/0`。如需解释原因，使用可选的语音备注，无需填写文字或录音才能提交。

## 肺野与六区

点「自动肺野 / 六区」后，模型在本机后台运行。可以继续查看其他病例，结果只关联其来源胸片；再次查看时恢复对应缓存。模型不会填写整片质量或六区密集度。

自动结果以六色叠加显示。核对患者左右、肺野范围及四个定位点：R-A / L-A 是右 / 左肺尖，R-D / L-D 是右 / 左膈顶。分界由各侧肺尖到膈顶的垂直距离三等分计算，叠加仅保留肺野内的部分。

| 操作 | 用途 |
| --- | --- |
| 修正肺野 | 打开原生 Segment Editor，选择患者右肺或左肺，用 Paint / Erase 修改；支持编辑器撤销 |
| 调整分界 | 解锁定位点，在图上拖动肺尖、膈顶；六区随定位点重新计算 |
| 显示分区 | 控制叠加可见性，不删除分区数据 |
| 确认分区 | 核对完成后确认；黄色表示待确认，绿色表示已确认 |
| 清除分区 | 清除当前记录的分区，使本次完成不再要求确认；已保存修订可在历史中追溯 |

任何肺野或定位点修改都会撤销确认，按钮重新变黄，需要再次确认。机器初始肺野和定位点分别保留，医生修正不覆盖初始结果；不同读者的修正和确认独立。膈顶初始点仅为算法估计，需要人工核对。

## 点与区域

「点与区域」默认展开，已有标注逐条显示，点击一行选中；超过可见行数后滚动列表。选中后可在下方改名、删除，也可直接在图上拖动点或顶点。

- 「＋ 标注点」：在胸片内单击放置一个点，放置后自动回到查看状态。
- 「＋ 圈选区域」：依次单击放置至少三个不同顶点，右键结束，末点自动连回首点。
- 「继续绘制」：对尚未完成的区域继续加顶点；绘制中可结束放置。

区域是多边形，矩形也按四个顶点保存。未完成、交叉、重复顶点或面积为零的轮廓可作为草稿保存，但需要修正后才能完成病例。点和顶点须留在图像内；尚未落点的鼠标预览不会保存。

## 语音备注

录音位于病例导航下方、整片质量上方。「开始录音」使用系统默认麦克风，按钮显示时长；停止后可从列表选择录音并回放或移除。一例可以录多段，录音与胸片和读者共同关联。

切换病例、切换读者或关闭前会先停止并保存录音。第一次使用须允许麦克风访问；失败时检查系统麦克风许可和默认输入设备。录音不做转写，评价及不可评原因可直接口述，录音本身是可选项。

录音分块刷盘，意外中断后重新打开同一项目会检查可恢复片段。有效片段作为中断录音恢复，不添加空音频。移除只影响当前记录；已保存历史所引用的音频可能仍被保留并包含在导出中。

## 完成条件与保存

「完成并下一例」检查下表。未满足的区域标红，已满足标绿并显示 ✓；六个评分行也分别反馈状态。按钮汇总缺项，悬停可查看说明。

| 区域 | 满足条件 |
| --- | --- |
| 整片质量 | 已选 1–4 级任意一级 |
| 六区评分 | 每区都已评分或选「不可评」，没有「未评」 |
| 肺野与六区 | 未生成分区，或已有分区已由当前读者确认 |
| 点与区域 | 留空，或每个已有标注都有效；区域无未完成、交叉等几何问题 |
| 语音备注 | 不要求录音；正在录音时先停止并成功保存 |

分区、点 / 区域和录音是可选项，空白不会新增必填要求。完成后的医学标注若再次修改，会恢复为草稿；单纯查看时的缩放、平移及灰度调整不改变完成状态。

滑杆评分立即保存；质量及空间修正一般在停止修改约半秒后保存，切换前会主动刷新。保存失败时显示红色错误和「重试保存」，并阻止切换病例、读者及关闭，当前输入保留。排除磁盘、权限或附件问题后重试，不要把失败提示当作已保存。

## 看图工具与完整 Slicer 界面

胸片上方的工具栏提供：

| 工具 | 用法 |
| --- | --- |
| 窗宽窗位 | 在片上按住左键拖动；实时显示数值，仅改变显示亮度与对比度 |
| 缩放 / 平移 | 滚轮缩放、中键拖动平移 |
| 适应窗口 | 恢复完整胸片的视野 |
| 原始灰度 | 恢复加载该片时的窗宽、窗位与灰度映射 |
| 完整 Slicer 界面 | 展开原生工具栏、模块选择器和视图控制；「精简标注界面」返回 |

选择查看工具会结束放点 / 圈选或关闭肺野编辑；进入放置模式时，查看模式的高亮会取消。切换完整界面不清空评分和标注，切到其他模块后仍可从图像上方返回。

图像按存储的像素方向显示，不把缺失的三维方位信息当作已知解剖方位。像素坐标不随查看操作改变，左右请核对片内标记。

## 导出

「导出结果」选择目标文件夹，生成一个带读者编号和时间的独立子目录。范围是当前病例列表、当前读者，包含未评病例、草稿、已完成记录和修改历史。其他读者需切换编号后分别导出。

评分 CSV 适合表格分析；空间 CSV 记录点和顶点；JSON 保留完整结构及历史；WAV、肺野掩膜和六区标签图通过相对路径关联。交付时保留整个导出文件夹，勿只移动 JSON。详细作用及字段见 [数据格式规范](data-format.md)。

## 本地项目与备份

```text
local-data/
├── last-project.json        # 上次打开的源目录与项目目录
├── slicer.log               # 启动日志
├── models/                  # 下载并校验的模型权重
├── projects/<目录摘要>/
│   ├── annotations.sqlite3  # 所有病例、各读者记录与修订历史
│   ├── assets/audio/        # 录音附件
│   ├── assets/masks/        # 不可变肺野掩膜
│   └── model-inputs/        # 本地模型输入，可含影像像素
└── qa/                      # 独立测试项目及演示素材生成过程
```

项目按所选源目录的完整路径建立；移动或重命名原始目录后，不会自动找到原项目。原始文件内容哈希用于防止同一图像编号沿用变化前的标注，遇到检查失败应核对数据或建立新项目。

备份前关闭使用该项目的标注窗口，再复制完整项目目录及原始 DICOM。运行中备份须使用 SQLite 在线备份机制并保留相关附件，不能只复制活动数据库文件。导出主要用于分析和交付，不是界面支持的项目导入 / 恢复格式；恢复工作环境需要本地项目和原图。

## 安装与启动排查

普通评分使用 Slicer 内置组件；模型、录音和回放使用项目 `.venv`。出现依赖或权重未准备提示时，在仓库目录重新运行 `mise exec -- python scripts/prepare_runtime.py`。脚本安装直接依赖的指定版本，不使用全局 Python；依赖文件未锁定完整传递依赖树。

Mac 启动路径不同时，用 README 的 `SLICER_APP=... ./启动尘肺标注.command` 命令指定。终端中的临时环境变量不会自动传给另一次 Finder 双击启动。也可在 Slicer 附加模块路径中加入仓库内 `PneumoconiosisAnnotator` 目录，重启后从 Research 分类打开模块。

「项目正由另一个窗口使用」表示项目锁阻止并行写入，先关闭使用该项目的其他窗口。该锁不构成跨网络盘的多机协作机制。

## 开发检查

核心测试命令见 README。集成检查在独立 Slicer 进程内运行，使用仓库相邻的 `2023Sample`，结果写入忽略的 `local-data/qa/`。按每组的检查脚本、恢复脚本顺序执行：

| 检查 / 新进程恢复 | 范围 |
| --- | --- |
| `slicer_smoke.py` / `slicer_restore_check.py` | 病例、评分、保存与导出 |
| `slicer_spatial_check.py` / `slicer_spatial_restore.py` | 原生鼠标放点、多边形、编辑、切换与持久化 |
| `slicer_features_check.py` / `slicer_features_restore.py` | 真实模型推理、肺野修正、确认、约一秒实际录音及回放 |

例如在 macOS 上执行第一个脚本（先在终端设定实际的 `SLICER_APP`，随后分别替换脚本名）：

```sh
MODULE_PROJECT="$PWD"
cd "$MODULE_PROJECT/local-data"
"$SLICER_APP/Contents/MacOS/Slicer" \
  --disable-settings --ignore-slicerrc --no-splash --testing \
  --additional-module-path "$MODULE_PROJECT/PneumoconiosisAnnotator" \
  --python-script "$MODULE_PROJECT/scripts/slicer_smoke.py"
```

文档截图使用 `scripts/capture_docs_preview.py`：将仓库内的 ImageGen 合成 PNG 封装成独立演示 DICOM，在独立项目中调用真实插件并截图。它不打开患者样本、不录音、不改动实际标注项目；合成输入和截图不能用于模型准确率验证。
